# 섹터 매치 발견·체험·보상

2026-11-18 사용자는 직전 제안대로 구현·검증·main 커밋·푸시를 승인했다. 기존 브랜드와 화면 구조를 유지한다.

## 승인된 방향과 구현 판단

메인 상단 카드와 스크롤 후 데스크톱 오른쪽 아래 플로팅을 조합한다. 상단만 두는 방식보다 재진입이 쉽고, 항상 큰 플로팅만 두는 방식보다 본문 가림을 줄인다. 모바일은 상단 카드만 제공한다. 닫기·접기, 키보드 초점, 모션 축소를 지원하며 실제 서버 대진의 준비/접수/마감/결과/장애 상태에 맞는 문구를 쓴다. 첫 등장만 짧게 전환하고 반복 부유 애니메이션은 쓰지 않는다.

초기 보상은 첫 정상 선택 저장 배지·월별 시즌 점수·본인 확정 결과 카드다. 한국시간 현재 월을 시즌으로 사용하고 대진 종료일이 그 월에 속하면 포함한다. 유효 적중1점, 실패0점, 동률/무효는 적중·실패 제외, 미확정0점. 최신 정산 버전으로 매번 서버에서 계산하므로 정정도 반영되고 중복 발급은 없다. 첫 참여 배지는 실제 본인 저장 기록이 존재하면 표시한다. 현금·이용권 교환이나 전체 순위는 추가하지 않는다.

본인 보상 API는 인증 후 user_id를 명시해 읽고 private/no-store로 응답한다. 기존 원장을 읽으므로 새 DB·스키마·권한은 불필요하다. 월별 선택은 페이지를 끝까지 읽어 잘라낸 점수를 전체 성적으로 표현하지 않는다. 공개12대진 조회 제한과 별개다.

확정된 본인 결과의 미리보기·PNG 내려받기를 제공한다. 카드에는 비교기간, 선택, 양쪽 가격변동률, 결과, 버전, 생성 시각을 넣고 개인정보는 넣지 않는다. 사용자가 버튼으로 내려받거나 공유 텍스트를 복사하며 서버 공개 프로필·공유 URL 저장소는 만들지 않는다. 이미 내려받은 이미지는 정정 이후 자동 갱신되지 않음을 알린다. 클라이언트가 제공한 점수로 서버 기록을 만들지 않는다.

가상49명은 고정된 가상 선택을 가진 연습 참가자다. 화면/결과에 '가상'을 표시하고 실제 참여 수·원장·보상·공식 순위에 합산하지 않는다. 로그인 없이 은행/조선을 골라 49명의 선택 분포와 비교한다. 가짜 시세·수익률·승패를 만들지 않는다. 실제 접수 보류 중에도 체험할 수 있다.

## 화면·경계

- 메인: 기존 시세/온보딩 안내 이후 매치 카드. 실제 조회 장애는 준비나0명으로 숨기지 않으며 체험 링크는 유지한다.
- 매치: 기존 가격 확인 중 안내와 실제 대진, 별도 가상 체험, 본인 보상/확정 결과 공유.
- 팔레트/타입: 기존 bg-background/bg-surface-2, text-foreground/muted, primary 골드, success/danger와 font-display를 재사용한다. 맞대결 양쪽 이름과 VS를 주 시각 요소로 한다. 새 폰트·의존성을 추가하지 않는다.
- 기존 pilot enabled:false, 실제 종가 검증 장애·접수 날짜·기존 정산·noindex는 변경하지 않는다.
- 측정은 기존 trackEvent로 노출/진입/체험 선택/카드 내려받기를 구분한다. 개인정보를 보내지 않고 실제 GA 수집이나 재참여 향상은 별도 확인이다.

## 완료 기준

준비/장애/접수/마감/결과 카드와 모바일/데스크톱 플로팅 동작,49명 고정·실제 기록 비접촉, 인증/소유자 필터/캐시 차단, 월 경계·최신 정정·동률/무효·1000행 초과 페이지, 이미지 개인정보 미포함·내려받기 실패 처리를 검사한다. 적절한 단위/E2E·타입·lint·production build 및 독립 리뷰/QA 후 main에 저장하고 운영 URL의 핵심 흐름을 확인한다. 실제 OAuth 사용자를 생성하거나 실제 참여 결과를 꾸며 검증하지 않는다.
