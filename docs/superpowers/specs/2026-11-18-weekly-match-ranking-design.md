# 실제 참여 집계와 공개 동의 순위

사용자 요청: 참여 인원이 보이도록 하고 보상을 자랑할 순위 리스트를 제공한다. 실제 참여하지 않은49명을 실제 이용자처럼 표시하는 부분은 구현하지 않는다. 실제 집계로 N명 참여 중을 표시하고 가상 연습은 기존처럼 명확히 구분한다. 기존 main 커밋·푸시·운영 배포 권한은 유지한다.

## 최소 설계

별도 순위 페이지 대신 기존 `/weekly-match#rankings`에 월별 공개 순위를 넣고 메인 카드·플로팅·보상 영역에서 연결한다. 실제 대진 선택 기록을 round별 고유 사용자 수로 집계한다. 대진이 마감되면 N명 참여, 접수 중이면 N명 참여 중으로 표시하며 조회 중/장애는0으로 위장하지 않는다. 고정된49는 실제 집계에 포함되지 않는다.

개인 기록은 비공개 기본값을 유지한다. 로그인 사용자가 별명(영문/한글/숫자/공백/_/- 2~16자)을 지정하고 순위 공개에 명시적으로 동의해야 공개한다. 공개하지 않으면 기존 보상·선택 기능은 그대로 이용한다. 이메일/실명/개인 선택/계정 ID는 순위에 노출하지 않는다. 별명은 대소문자 무시 유일하며 철회 후 다음 API 응답에서 제거한다.

점수는 기존 월별 규칙 그대로: 한국시간 현재 월 종료 대진의 최신 확정 결과에서 적중1·실패0, 동률/무효 제외, 최신pending이면 미확정이다. 유효 확정 참여1회 이상+공개동의인 사용자만 순위에 들어간다. 같은 점수는 공동 순위, 적중/유효 참여 횟수를 함께 보여준다. 상위50명과 실제 전체 순위 자격 인원을 제공한다. 초기에0명이면 실제 기록이 쌓일 때 제공한다는 빈 상태를 쓴다. 가상 순위·가상 보상·현금성을 추가하지 않는다.

## 권한·저장

새 public_profiles 표에는 auth UID와 공개 별명·동의 여부만 보관한다. RLS본인만읽기/쓰기/삭제, raw표anon노출없음. 기존 entries/round/settlement grants는 유지한다. 집계 RPC는 좁은 SECURITY DEFINER/search_path=''로 필요한 숫자와 공개 동의 별명만 반환하고 service_role만 실행하게 한다. 공개 Next API가 서버 자격으로 호출하며 publicno-store. 본인 profileAPI는 기존인증·user_id 명시/private no-store를 유지한다. 마이그레이션은 공식CLI로 만들고 isolatedPG에서 멱등성·RLS·grants·별명충돌·철회·정정·동점·가상미포함 검증 후 운영 적용한다.

## 보존·검증

기존 대진/개인선택/정산 원본/접수마감·베타disabled·가격검증 장애는 유지한다. APIunit/SQL실행/UI/E2E·타입·lint·productionbuild·독립리뷰/QA→main푸시→배포된 사이트/실제운영집계 확인. 실제 OAuth 사용자는 만들지 않으며 결과가 없는 운영 순위를 시험용 데이터로 채우지 않는다. 원장이나 공개 동의 없는 기존 사용자를 자동 공개하지 않는다.
