# 주간 매치 조기 공개: 단기 베타

승인: 사용자가 2026-11-18에 별도 단기 베타로 검증을 앞당기고 가장 빠른 시점에 시작하도록 지시했다. 기존 main 커밋·푸시·배포 승인도 유지한다.

목표는 실제 참여와 결과 검증을 앞당기는 것이다. 한국시간 11/18 18:00 이후 실제 기준 종가를 확보하면 `kr-pilot-2026-11-19` 접수를 시작하고, 11/19 09:00 마감, 11/19 18:00 이후 정산한다. 수능일 11/19 정규장 시간 변경을 공식 자료로 재확인한다. 오전 9시 마감은 지연 개장보다 이르므로 보수적으로 유지한다.

## 접근 비교와 결정

- 기존 대진 날짜 수정: 게시된 불변 원본·자동 복구를 깨뜨리므로 사용하지 않는다. 기존 `kr-2026-11-16`과 11/20 정산은 그대로 유지한다.
- 과거 가격 재현만 수행: 지금 산식·보류·무효를 검사할 수 있지만 실제 접수·잠금·정산의 시간 경과 검증을 대신하지 못한다.
- **선택: 과거 실제 가격의 격리 재현 + 별도 단기 베타.** 기존 원장과 분리해 1일 매치임을 화면·제목에 표시한다. 수익·적중·시즌 성과를 꾸며내지 않는다.

## 계약

- 기존 스키마·인증·RLS·정산 산식·가격 출처·무효 유예기간을 재사용한다. 원장 변경·삭제·권한 우회·운영용 가짜 사용자/선택 생성은 없다.
- 새 manifest `config/weekly-match-pilot.json`은 은행 7종목과 조선 5종목을 고정한다. 기준일 11/18, 종료일 11/19이며 미래 가격은 넣지 않는다. 공식 달력·기업행사 검토가 통과해야 활성화한다. 결측이나 의심 행사 시 임의로 종목을 제외하지 않는다.
- 기존 workflow 안의 명시적 2개 matrix 항목으로 기존 대진과 베타를 각각 처리한다. 실패 격리, 라운드별 감사 경로·artifact 이름을 사용하며 기존 기준 artifact는 그대로 복구한다. 날짜나 대진은 자동 생성하지 않는다.
- 한국시간 18:00 이후의 일일 실행에 맞춰 게시·정산한다. GitHub 예약 지연은 가능하며 실제 게시 영수증과 공개 API 확인 전에는 접수 시작 완료로 보고하지 않는다. 마감이 지난 미게시 베타는 중단하며 날짜를 몰래 연장하지 않는다.
- 일반 화면에 `섹터 매치` 베타 진입점을 제공한다. 실제 접수 여부·비교 기간·마감·결과는 서버 기록으로 표시한다. 베타 준비/제한과 가격 변동률 비교임을 명시하며 noindex·sitemap 제외를 유지한다.
- 실제 OAuth/정상 선택 저장은 사용자가 직접 확인하는 방식으로 진행한다. 자동 테스트·합성 세션을 실제 사용자 인증 검증으로 표현하지 않는다.

## 검증·복구

과거 실제 가격 재현, 두 라운드 처리의 비간섭, 기준 원본 불변, artifact 충돌 방지, 공개·개인 API 경계, 베타 설명, 데스크톱/모바일 진입을 확인한다. 타입·lint·단위·격리 DB·production build 및 독립 리뷰를 수행한다. 베타 중지는 베타 manifest만 `enabled:false`로 전환하며 기존 대진 처리는 유지한다. 새 플랜·유료 서비스·외부 메시지 발송은 추가하지 않는다.
