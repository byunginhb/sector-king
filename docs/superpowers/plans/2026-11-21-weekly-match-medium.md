# 섹터 매치 운영 점검과 중간 크기 조정

사용자 목표: 현재 운영 상태를 확인하고 홈의 지나치게 작은 섹터 매치 카드를 읽기 쉬운 크기로 조정한다.

## 범위

- 기존 브랜드 배경·금색 강조·폰트를 유지한다. 홈 카드 하나에서 제목/상태, 큰 대진명, 비교 기간, 짧은 설명과 진입 버튼을 보여준다.
- 데스크톱은 약 150~200px, 모바일은 약 200~280px 높이를 목표로 한다. 이전 70/90px보다 선명하고 최초 249/528px보다 작게 유지한다.
- 플로팅과 연습/순위의 중복 CTA는 복원하지 않는다. 참여 인원은 실제40명 이상일 때만 표시하는 기존 기준을 유지한다.
- API·가격·DB·정산·접수 마감·자동 작업과 비활성 다음 대진 설정은 변경하지 않는다.
- 공개 대진·순위 API와 최근 Actions 결과/artifact를 읽어 현재 정산/신규접수/예약지연을 구분해 기록한다. 자동 집계 결과를 독립 가격 원장 검증으로 표현하지 않는다.

## 검증과 배포

기존 단위·E2E의70/90px 기준을 갱신하고 실제 1440/390/320px 화면의 높이·가로 넘침·버튼·플로팅 부재를 확인한다. 준비/접수/마감/확정/조회장애와 실제40명 기준을 유지한다. 독립 리뷰 후 main커밋·푸시·운영URL검증까지 수행한다.

참여율 개선은 미측정 가설이다. 새 접수 개시와 가격 원장 대조/Actions 지연 개선은 이번 화면 크기 변경과 분리해서 남긴다.
