# 섹터 매치 노출 축소

목표: 초기 참여 숫자로 생기는 부담과 홈 점유를 줄인다. 실제보다 인원을 부풀리지 않는다.

- 홈은 기존 어두운 배경·금색 포인트·기존 폰트를 유지하는 작은 가로 카드 하나다. 왼쪽 대진/상태, 오른쪽 기존 진입 버튼만 표시하고 모바일도 짧은 두 줄 안팎으로 배치한다.
- 플로팅과 그 접기/닫기·모달 감지 로직, 홈의 연습·순위 중복 링크와 장문 설명을 삭제한다. 상세와 전역 메뉴의 진입은 유지한다.
- 홈·대진·공개 순위의 인원 숫자는 실제 40명 이상일 때만 표시한다. 그 전에는 상태와 결과 안내를 표시한다. 실제 API·집계·점수·원장은 유지한다.
- 순위가 비었을 때는 확정 결과가 모이면 순위를 볼 수 있다고 안내한다. 보상·공개동의·철회·가상 연습은 기존 상세에서 유지한다.
- 단위 검사로 0/39/40/49 경계와 장애를 확인하고, Chrome에서 1440/390px 카드 높이·가로 넘침·스크롤 후 플로팅 부재·상세 진입을 확인한다. 기존 E2E의 삭제된 UI 기대값도 갱신한다.
- 독립 리뷰/QA 뒤 main 커밋·푸시와 실제 배포를 확인한다. 가격 검증·대진 운영·DB·권한은 이번 범위 밖이다.

검증 목표는 노출 면적 축소와 실제 인원 표시의 정합성이다. 참여율 개선은 측정 전 가설이다. view_promotion 및 select_content의 home_card 이벤트는 유지하며, 삭제된 home_floating 이벤트는 더 이상 발생하지 않는다.
