# Lint 정리와 참여·측정 확인

기준일: 2026-11-09 America/Toronto. 상태: 영향 범위별 수정·로컬 및 독립 검증 완료.

## 기준선과 수정 범위

`pnpm lint` 기준 오류 71개·경고 13개를 재현했다. 제품 20개 파일의 오류 50개·경고 7개와 `.harness/`에 생성된 일회성 검증 파일의 오류 21개·경고 6개를 구분했다. 생성된 감사·검증 산출물만 ESLint 검사에서 제외하고 제품 검사 규칙과 엄격도는 유지한다.

금액·통화·API 응답·주간 경기 규칙·사용자 권한·DB를 변경하지 않는다. 로그인·가입·이메일 발송·구독 동의를 새로 요구하는 흐름도 추가하지 않는다. 기존 사용자의 저장된 설정을 유지한다.

React 상태·구독의 검토 기준: [useSyncExternalStore](https://react.dev/reference/react/useSyncExternalStore), [set-state-in-effect](https://react.dev/reference/eslint-plugin-react-hooks/lints/set-state-in-effect). 특히 snapshot은 값이 바뀌지 않으면 같은 값을 반환하고 서버·최초 hydration의 출력이 일치해야 한다. 기존 Next 16.1.4 / React 19.2.3 / pnpm을 유지한다.

## 다음 단계와 사용자 부담

Lint와 회귀 검사가 끝나면 운영 로그인·세션 복귀 경계와 검색·전환 측정을 확인한다. 사용자가 반복 승인하거나 매번 작업을 실행할 필요가 없도록 기존 연결과 자동 운영을 재사용한다. 계정 공급자가 사용자 본인에게 요구하는 실제 로그인·동의까지 대신할 수 있다고 약속하지 않는다.

2026-11-09 재확인에서 사용자 브라우저 host가 여전히 연결되지 않았다. 비밀번호·키·쿠키를 채팅으로 요청하거나 다른 경로로 세션을 추출하지 않는다. 연결 없이 가능한 공개 로그인 화면·OAuth 시작·안전한 오류 복귀·측정 태그·이벤트 전송 검사는 계속한다. 실제 OAuth 성공과 본인 선택 저장은 별도 미검증으로 기록한다.

운영 초기 HTML에서 GA4 `G-SVC5PKGV3M`과 gtag 로딩을 확인했다. Google 검증 meta가 없다는 사실만으로 Search Console 미등록을 단정하지 않는다(DNS 등 다른 검증 경로가 있을 수 있다). 현재 세션에는 GA/Search Console 보고서를 읽을 연결이 없고 사용자 브라우저도 사용할 수 없어, 보고서 수신·색인·노출·클릭은 아직 확인하지 못했다. [Google DebugView 안내](https://support.google.com/analytics/answer/7201382?hl=en)에 따라 실제 보고서 확인과 네트워크 전송 확인을 구분한다. 모의 성공 이벤트를 실제 전환으로 전송하지 않는다.

## 검증 결과

구현·독립 검증·운영 배포 후 실제 결과를 기록한다. 전체 lint를 통과하기 전에는 해결 완료로 표시하지 않는다.

### 로컬·독립 검사 완료

- `pnpm lint --max-warnings 0`: **전체 오류 0·경고 0**, 595개 검사 대상 파일. 제품 50개 오류·7개 경고는 코드에서 해결했고, 나머지는 생성 검증 파일의 범위 제외다. eslint-disable·규칙 완화·의존성 추가 없음.
- 전체 Vitest: **50개 파일 / 539개 통과·기존 연동 검사 11개 건너뜀**. 새 회귀 16개는 재렌더의 금액·방향·DOM 유지와 검색·저장 상태·실제 hydrateRoot 동작을 검증한다.
- `pnpm exec tsc --noEmit --incremental false` 통과. `pnpm exec next build` 통과. 로컬 `.env.local`의 기존 자리표시자 URL은 실행 시 오류가 나므로, 실제 브라우저용 빌드는 공개 테스트 URL과 가짜 anon 키를 명시해 다시 수행했다. 환경 파일이나 운영 비밀은 변경하지 않았다. 로컬 build는 기존 시장 SQLite를 보존하기 위해 DB 다운로드를 생략했다.
- 독립 코드·보안 리뷰 승인, 동결 입력 26개 일치. 정산·가격·권한 변경이나 미해결 치명적·높음 결함 없음.
- 독립 Chrome E2E **34개 통과**: 검색 진입 14개·주간 매치 20개. 로그인 fixture는 실제 OAuth 검증으로 집계하지 않았다.
- 영향 화면 **10건**(5개 경로 × 1440/390px)과 **8개 상호작용 묶음** 통과. 검색의 재열기·화살표·Esc·Ctrl-K·Enter, 애니메이션 일시정지, 기간·국내 필터, 안내 닫기·재접속 상태를 확인했다. hydration·페이지 예외 0건, 가로 넘침 없음.
- 초기 검사 스크립트의 기존 radio를 button으로 찾는 선택자 오류는 보존하고 고친 뒤 재검증했다. 제품 결함과 혼동하지 않는다. 로컬에서만 나타난 Vercel Speed Insights 자산 404와 기존 일부 페이지의 중복 H1은 이번 lint 변경과 무관한 관측으로 남겼다.

### 다음 단계 확인

운영 인증 콜백에서 코드 누락·인증 취소·외부 복귀 주소를 실제 요청해 모두 같은 출처의 로그인 오류 안내로 돌아오는 HTTP 307을 확인했다. 공개 Google OAuth 시작은 HTTP 302와 기존 Supabase 콜백을 반환했다. 사용자 인증이나 계정 생성은 실행하지 않았다. 기존 GA4 페이지 조회 전송의 HTTP 204도 관측했다. 로그인 성공 이벤트·관심 등록 성공·GA 보고서 수신·Search Console의 실제 검색 성과는 확인하지 못했다. 네트워크 수신 응답을 실제 사용자 전환이나 노출 증가로 해석하지 않는다.

브라우저 host가 연결되면 실제 사용자의 기존 로그인으로 세션 유지·복귀를 확인하고, 유효 대진이 게시된 뒤 선택 저장·변경을 검증한다. 그 전까지 주간 매치 사용자 진입 플래그·noindex·sitemap 제외를 유지한다. 이미 등록된 단일 라운드 일일 작업과 날짜를 바꾸거나 새 가입·동의·수동 운영 절차를 추가하지 않았다.

운영 적용은 최신 main SHA와 Vercel production READY를 대조하고 같은 읽기 전용 검사를 운영 URL에서 수행한다. 원격 배포·브라우저 증거는 `.harness/lint-cleanup/`에 보관하고 최종 보고에서 로컬 결과와 구분한다.
