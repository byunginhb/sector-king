# 글로벌 자금 지도 — 기획

> 상태: **구현 완료 (P0·P1·P2)** · 기획 2026-10-12 · 구현 2026-10-13
> 구현 지도: [implementation.md](implementation.md) — 파일 위치·데이터 흐름·운영 주의점
> 개념: [자금 흐름의 세 가지 뜻](../../concepts/money-flow-definitions.md) · 데이터: [데이터 소스](data-sources.md)

## 1. 왜 만드나

Sector King 의 질문은 "시장의 돈은 어디로 흐르는가"다. 지금은 **주식 안에서만**(산업 → 섹터 → 종목) 답한다. 하지만 돈은 주식 밖으로도 나간다 — 달러 현금, 국채, 금, 비트코인으로. 주식 전체가 빠지는 날 "반도체에서 방산으로 이동"만 보여주면 큰 그림을 놓친다.

이 페이지는 **주식 위의 한 층**을 더한다:

```
[전 세계 자산]  주식 · 채권 · 금 · 원자재 · 크립토 · 현금   ← 신규 (이 페이지)
      └ [주식]  산업 9개                                    ← 기존 홈/자금흐름
           └ [섹터] 143개                                   ← 기존 /sectors
                └ [종목] 602개                              ← 기존 /stock
```

## 2. 사용자가 이 페이지에서 얻어야 할 답 (우선순위 순)

1. **지금 돈은 위험 쪽으로 가나, 안전 쪽으로 가나?** (한 줄 결론)
2. **물 전체는 늘고 있나 줄고 있나?** (유동성 조류)
3. **어느 자산군이 커지고 어느 자산군이 작아졌나? 그 순서는?** (가치 변화)
4. **회전은 어디서 어디로 진행 중인가?** (상대강도 회전 궤적)
5. **실제로 돈이 들어간 통로는?** (MMF·스테이블코인·ETF 순설정)
6. 주식이 받는 쪽이라면 → **주식 안에서는 어디로?** (기존 산업 자금흐름으로 연결)

## 3. 핵심 설계 원칙

- **측정한 것만 화살표로 그린다.** 자산군 A의 가치 감소와 B의 가치 증가 사이에 선을 긋지 않는다(이유: [개념 문서](../../concepts/money-flow-definitions.md#출발점-순유입은-직접-관측되지-않는다)). "어디서 어디로"는 **회전 궤적(RRG)**으로 답한다 — 상대 강도가 어느 자산에서 빠져 어느 자산으로 옮겨가는지는 정직하게 보여줄 수 있다.
- **세 층을 섞지 않는다.** 조류(①) · 가치 변화(②) · 실제 유출입(③)은 섹션도 단위 표기도 분리한다.
- **달러는 잣대다.** 모든 값이 USD 표시라 달러 강세는 다른 자산을 일괄 깎는다. 달러 인덱스는 버킷이 아니라 상단 기준 띠에 따로 둔다.
- **새 인프라 최소화.** 기존 `update_indices.py`(yfinance 5년 이력) + `update-data.yml`(평일 4회) 파이프라인에 편승한다. 실적 캘린더·공모주와 같은 방식.

## 4. 추적 자산군 (MVP 유니버스)

| 그룹 | 자산 | 위험/안전 | 규모 산출 |
|------|------|-----------|-----------|
| 주식 | 미국 주식, 한국 주식, 미국 외 세계 주식 | 위험 | 지수 수익률 × 시가총액 추정 |
| 채권 | 미국 장기국채, 투자등급 회사채, 하이일드 | 장기국채=안전, 하이일드=위험, IG=중립 | 지수/ETF 수익률 × 시장 규모 추정 |
| 원자재 | 금, 원유, 구리 | 금=안전, 원유·구리=위험(경기) | 금=지상 재고 × 가격 / 원유·구리=가치 미집계(가격 신호만) |
| 크립토 | 비트코인, 이더리움 | 위험 | 유통량 × 가격 |
| 현금 | 미국 단기국채(T-bill) | 안전 | MMF 잔고(실측, ③) |
| 기준자 | 달러 인덱스, 원/달러 | — | 버킷 아님 |

심볼·규모 상수는 [데이터 소스](data-sources.md) 참조. 원유·구리는 시장 "가치"가 정의되지 않아(재고 개념이 모호) 가치 집계에서 빼고 회전 궤적에만 넣는다.

### 5.2 섹션별 상세

**한 줄 결론 (규칙 기반, LLM 미사용)**
- 위험 선호 점수 = 위험 자산군 평균 수익률 − 안전 자산군 평균 수익률 (기간별, 동일가중).
- 조합: `{위험자산 선호|안전자산 선호|중립}` · `{유동성 확대|축소|횡보}` · `{달러 강세|약세}`.
- 임계값(예: ±1%p)은 상수 하나로 두고 백테스트 후 조정. 문장은 템플릿 조합만.

**① 유동성 조류**
- 순유동성 = 연준 총자산 − TGA − 역레포. 주간 라인 1년 + 최근 4주 변화.
- 표기: "확대 중 / 축소 중". "상승 신호" 같은 인과 표현 금지.

**② 자산군 지도 + 가치 증감 순위**
- 트리맵: 기존 `lib/treemap.ts`(squarify) 재사용. 크기=규모(USD), 색=기간 수익률 발산 스케일(시총 지도 종목 레벨과 같은 rose↔slate↔emerald).
- 발산 막대: 기간 가치 변화액(USD) 내림차순. 기존 `market-size-metric-bars` 재사용 검토.
- 부제 고정: "기간 시가 가치 변화 — 자산 간 이동액이 아님".
- 그룹 클릭 → 그룹 내 세부 자산 드릴다운(시총 지도의 섹터→종목 드릴다운 패턴).

**④ 회전 궤적 (상대 회전 그래프, RRG 단순화판)**
- 이 페이지의 "어디서 어디로"에 대한 핵심 답.
- 기준 바스켓 = 추적 자산군 동일가중 평균(USD) — "한정된 돈 전체" 대비 상대 강도라는 서비스 관점과 맞춘다.
- x(상대 강도) = 100 × RS / SMA(RS, N), RS = 자산 가격 / 기준 바스켓.
- y(상대 모멘텀) = 100 × x_t / x_{t−k}.
- 사분면: 주도(x>100,y>100) → 둔화 → 약세 → 개선. 점은 현재, 꼬리는 지난 8~12주 주간 경로.
- 표준 JdK RRG(독점 공식)가 아니라 공개 단순화판임을 설명 패널에 명시.
- recharts ScatterChart + Line(꼬리)로 구현(이미 의존성 있음).

**③ 실제 자금 통로**
- MMF 잔고, 스테이블코인 총발행량, 주요 ETF 순설정액. 숫자 카드 + 스파크라인.
- 이 섹션만 "유입/유출" 용어 사용 가능.

**하단 연결**
- "주식이 받는 쪽이라면, 주식 안에서는?" → 홈 자금흐름 / 산업 money-flow 링크. 서비스 전체가 위→아래로 이어지는 동선.

## 7. 단계별 로드맵

### P0 — MVP: 가치 변화 + 회전 (새 키 0개)
- yfinance 자산 심볼 이력 수집 (기존 파이프라인 편승)
- 규모 상수 + 가치 변화 계산 + 위험 선호 결론(유동성 없는 버전)
- 페이지: 결론 · 잣대 띠 · ② 트리맵/막대 · ④ RRG · 하단 연결
- **수락 기준**
  - [ ] 4개 기간 모두 자산군별 수익률·가치 변화가 계산되고, 수동 계산(스프레드시트)과 ±0.1% 이내 일치
  - [ ] KOSPI 수익률이 USD 환산 기준임을 유닛 테스트로 고정
  - [ ] RRG 사분면 판정 유닛 테스트(4사분면 각각)
  - [ ] 가치 변화 막대에 "자산 간 이동액이 아님" 부제, 화살표 없음
  - [ ] 초기 HTML 에 h1·요약 존재(SeoSummary), 모바일 가로 스크롤 없음, 라이트·다크
  - [ ] build/tsc/lint 베이스라인 유지

### P1 — 조류 + 실제 통로
- FRED: 순유동성(WALCL·WTREGEN·RRPONTSYD), MMF 잔고
- DefiLlama: 스테이블코인 발행량
- 페이지: ① 조류 섹션, ③ 통로 섹션(MMF·스테이블코인), 결론에 유동성 축 추가
- **수락 기준**
  - [ ] 순유동성 값이 FRED 원자료 수동 계산과 일치(단위: 백만$ vs 십억$ 혼동 검증)
  - [ ] 외부 API 실패 시 해당 섹션만 숨기고 페이지 200 유지
  - [ ] 주간 시리즈의 기준일을 화면에 표기(일간 데이터와 섞여 보이지 않게)

### P2 — 확장
- ETF 순설정 추정(수집은 P0 때부터 미리 시작해 이력 쌓아두기 권장)
- 한국 축: 고객예탁금·외국인 순매수(네이버 증권 API — KOFIA·KRX 직접 수집은 키·OTP 필요), 원/달러
- 홈 대문에 "글로벌 자금 한 줄 결론" 띠 노출
- 결론 임계값 백테스트, 가이드 글 1편(`/guide/cross-asset-flow`)

## 8. 하지 않는 것 (의도적 제외)

| 제외 | 이유 |
|------|------|
| 자산군 간 생키 다이어그램 | 측정 안 된 A→B 이동을 사실처럼 그린다. 개념 문서 표현 규칙 3 위반 |
| 부동산(실물) | 일별 시가 데이터 없음. 리츠(VNQ)는 주식의 일부로 이미 반영 |
| 전 세계 M2 합산 | 국가별 발표 주기·환율 처리 복잡도 대비 효용 낮음. 미국 순유동성으로 대표 |
| 유료 데이터(EPFR 펀드 플로우 등) | 비용. 무료 소스로 MVP 가치 검증 후 재검토 |
| 실시간 갱신 | 서비스 갱신 주기(평일 4회)와 일치시킴 |

## 9. 열린 질문 (구현 착수 전 확인)

- yfinance ETF `sharesOutstanding` 이 매일 갱신되는지 실측 필요 — 정체돼 있으면 P2 ETF 순설정을 발행사 공시(iShares/SPDR CSV)로 대체.
- 비트코인은 주말에도 거래된다. 주식 기준 거래일 캘린더에 맞춰 금요일 종가로 정렬할지(권장) 확인.
- 유료화 게이팅: 결론·조류는 공개(SEO 착지면), RRG 꼬리 길이·기간 1년은 Pro 후보 — `/admin/permissions` 카탈로그에 등록만 하고 기본은 open.
