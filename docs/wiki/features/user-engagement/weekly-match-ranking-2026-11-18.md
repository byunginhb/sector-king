# 실제 참여 인원과 공개 순위

## 제공 범위

- 홈은 대진명·비교 기간·상태·설명과 버튼을 갖춘 중간 크기의 카드 하나를 표시한다(2026-11-21 조정). 플로팅과 홈 연습·순위 중복 링크는 계속 제외한다. 실제 선택 원장의 대진별 사용자 수가 40명 이상일 때 접수 중에는 `N명 참여 중`, 마감 후에는 `N명 참여`를 표시한다. 대진과 공개 순위의 인원 숫자도 같은 기준으로 표시한다. 집계 실패를 0명으로 표시하지 않는다.
- 가상 49명 연습은 실제 참여·보상·순위에 합산하지 않는다. 가상 사용자를 실제 사용자로 표시하거나 운영 원장에 추가하지 않는다.
- 메인 카드에서 대진 상세로 들어간 뒤 개인 보상의 링크나 `/weekly-match#rankings`에서 순위를 확인한다.
- 월별 순위는 별명과 공개에 동의하고 유효 결과가 한 번 이상 있는 사용자만 표시한다. 기존 사용자의 자동 공개는 없다.

## 점수와 공개 정보

대진 종료일을 기준으로 한국 시간의 현재 월을 집계한다. 최신 정산의 적중은 1점, 실패는 0점이며 무승부·무효·미확정은 유효 참여에서 제외한다. 정정으로 최신 결과가 미확정이면 이전 적중도 제외한다. 같은 점수는 공동 순위이며 상위 50명과 전체 해당 인원을 표시한다.

공개 필드는 별명·순위·점수·적중·실패·유효 참여 횟수다. 사용자 ID·실명·이메일·개별 선택은 공개하지 않는다. 별명은 2~16자의 한글·영문·숫자·공백·밑줄·하이픈이며 대소문자를 무시해 중복을 막는다.

본인 공개 설정에서 동의를 해제하면 다음 순위 조회부터 제외된다. 현재 열린 다른 방문자의 화면은 다음 조회 또는 새로고침 시 반영된다. 개인 보상 기록은 유지한다. API는 캐시를 저장하지 않으며 UI의 순위 조회 유효 시간은 60초다.

## 저장소와 검증

새 `weekly_match_public_profiles`는 기본 비공개이고 본인만 조회·수정할 수 있다. 실제 참여 수와 순위는 서버 전용 집계 RPC가 제공한다. 원본 참여·정산 테이블의 기존 권한은 바꾸지 않는다.

`20261119042546_weekly_match_public_ranking.sql`은 별도 PostgreSQL 17에서 신규 17종과 기존 36종 검사를 통과했다. 운영 적용과 배포 여부는 실행 장부 `.harness/weekly-ranking-20261118/`의 릴리스 근거로 확인한다. 테스트 참가자는 격리 DB와 브라우저 모의 응답에만 존재한다.

실제 사용자 OAuth 로그인 후 공개 설정 저장은 사용자 계정으로 확인해야 한다. 자동 검사는 본인 권한·공개/철회·오류·공동 순위를 격리 환경에서 검증한다.

## 운영과 되돌리기

기존 대진·참여·정산·가격 검증·베타 비활성 설정은 유지한다. 순위 추가가 새 대진 개시나 정산을 실행하지 않는다. 현재 공개 순위가 비어 있으면 확정 결과가 모인 뒤 순위를 볼 수 있다고 안내한다.

문제 시 먼저 이전 앱 버전으로 복귀한다. 추가 테이블과 함수는 이전 코드에 영향을 주지 않으므로 즉시 삭제하지 않는다. 실제 사용자의 공개 설정이 쌓인 후 테이블을 삭제하면 설정이 유실되므로 별도 검토한다.

## 운영 DB 적용 기록 — 2026-11-19

기존 `sector-king` 프로젝트에 동일 SQL을 `weekly_match_public_ranking` 이름으로 적용했다. 운영 migration 버전은 `20261119044024`이며, 로컬 파일은 공식 CLI가 먼저 생성한 `20261119042546`을 유지한다. 전체 과거 migration 재실행은 하지 않았다.

적용 직후 기존 대진의 실제 참여는 0명, 현재 월 공개 순위는 0명, 새 공개 프로필은 0개였다. 기존 참여·정산 기록은 모두 적용 전과 같은 0개다. 프로필 RLS와 서버 전용 RPC 실행권한을 확인했고, 기존 service_role의 원본 참여 SELECT 차단도 유지됐다.

Supabase 보안 점검은 변경 전후 동일한 기존 경고만 반환했다. 신규 프로필·집계 함수 관련 경고는 없다. 기존 함수의 [search_path](https://supabase.com/docs/guides/database/database-linter?lint=0011_function_search_path_mutable)·[definer 실행권한](https://supabase.com/docs/guides/database/database-linter?lint=0028_anon_security_definer_function_executable)과 [유출 비밀번호 보호](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection)는 이번 순위 기능과 별도 점검 대상이다.
