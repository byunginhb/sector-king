# 섹터 매치 — 메인 발견·체험·개인 보상

2026-11-18 사용자가 승인한 메인 배치·초기 보상·가상49명 체험의 구현 범위다. 기존 [단기 베타 접수 보류](weekly-match-pilot-2026-11-18.md)는 유지한다. 이 기능 배포가 실제 접수 개시를 뜻하지 않는다.

## 이용 흐름

메인의 시세·온보딩 안내 다음에 은행 vs 조선 매치 카드를 둔다. 공개 API가 알려 주는 접수 준비/접수 중/마감/결과 확정에 맞춰 버튼이 바뀐다. 조회 실패는 장애로 표시하고 다시 불러오기를 제공한다. 공개 대진이 없어도 체험할 수 있다.

데스크톱은 상단 카드가 화면 위로 사라졌을 때만 오른쪽 아래 작은 플로팅이 나타난다. 접기·펼치기·닫기가 가능하며 모달·온보딩 중에는 숨긴다. 모바일은 상단 카드로만 안내하고 반복 부유 애니메이션은 쓰지 않는다.

`/weekly-match#practice`는 로그인 없이 두 섹터 중 하나를 골라 가상49명의 고정된 선택과 비교한다. 가상 은행26명·조선23명이며 실제 유저나 시세 예측이 아니다. 실제 참여 수·선택 원장·시즌 점수·보상·공식 순위에 합산하지 않는다. 연습 선택은 서버에 저장하지 않으며 가격·승패를 만들어내지 않는다.

## 보상 규칙

- 첫 참여 배지: 기존 본인 원장에 정상 선택 저장 기록이 있으면 표시한다. 연습이나 조회만으로 획득되지 않는다.
- 시즌: 한국시간 현재 월. 종료일(endDate)이 그 월에 속한 실제 참여 대진을 대상으로 한다.
- 적중1점·실패0점, 동률/무효는 적중·실패 집계 제외, 미확정0점. 최신 정산 버전을 사용하므로 정정 시 점수·카드도 달라질 수 있다.
- 별도 점수 발급이나 클릭 누적은 없다. 기존 서버 원장을 읽어 계산한다. 점수는 현금·이용권으로 교환되지 않는다.
- 확정된 본인 결과만 미리보기 후 PNG로 내려받거나 글로 복사한다. 비교기간·선택·양쪽 변동률·결과·버전·확정 시각을 담고 PNG에는 생성 시각도 표시한다. 실명·이메일은 포함하지 않는다. 공개 프로필/개인 결과 permalink는 만들지 않는다.
- 내려받은 이미지는 정정 이후 자동 갱신되지 않는다. 최신 버전으로 다시 내려받아야 한다. 다운로드 시작·공유 글 복사와 실제 외부 게시를 구분한다.

## 데이터·권한

새 `GET /api/me/weekly-match/rewards`는 기존 인증을 요구하며 private/no-store와 Vary:Cookie를 사용한다. authenticated client가 user_id 조건으로 본인 선택만 읽는다. 기존 service_role에 entries SELECT 권한이 없으므로 권한을 늘리지 않고, admin은 공개 대진/정산만 조회한다. 월별 대진은200개씩 끝까지 읽고 각200개 묶음의 본인 선택을 읽어 기본1000행 제한이나 공개12대진 제한 때문에 점수가 누락되지 않게 한다. 새 스키마·계정·실제 가상사용자 생성은 없다.

보상 조회 장애를0점으로 숨기지 않는다. 실제 Google OAuth와 운영 개인 결과는 사용자가 정상 접수 중 확인할 수 있으며 테스트 fixture를 이 검증으로 취급하지 않는다.

## 측정·중지

기존 trackEvent로 view_promotion(메인카드 노출), select_content(실제/체험 진입), weekly_match_practice_pick(가상선택), weekly_match_card_download(PNG시작), share(copy), weekly_match_dismiss를 전송한다. 이름/이메일/선택 원장은 분석 이벤트에 넣지 않는다. 실측할 지표는 발견→진입→정상 저장→결과 확인→다음 대진 재참여다. GA수집 성공이나 참여 상승을 구현만으로 보장하지 않는다.

UI를 중지하려면 IndustryDashboard의 WeeklyMatchHome 진입과 매치 페이지 practice/rewards 렌더를 제거하거나 이 변경을 revert한다. 운영 선택·정산 원장을 삭제하지 않는다. 기존 자동 작업/베타 enabled/접수 마감은 별도로 유지한다. 비밀키·유료 보상·광고·자동 외부 발행을 추가하지 않았다.
