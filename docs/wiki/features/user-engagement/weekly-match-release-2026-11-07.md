# 주간 매치 구현 검증 — 2026-11-07

국내 단일 대진의 접수·잠금·정산·내 결과 코드를 추가했다. **운영 접수는 미활성**이며 이번 검증을 실제 경기 출시로 표시하지 않는다.

## 제공 준비가 끝난 코드

- `/weekly-match`: 설명·규칙 SSR, 본인 선택 저장/변경, 서버 마감 거부, 잠금·집계 대기·승패·동률·무효·최신 정정 버전.
- Supabase migration 0018: 고정 구성·기준 원장, 본인 선택 RLS/RPC, 버전별 정산 원장. 클라이언트는 사용자 ID·점수·마감을 확정하지 않는다.
- 공개 API는 구성 이름·시간·변동률만 반환한다. 네이티브 가격과 선택·프로필은 공개하지 않는다.
- 일봉 수집 스크립트는 기준·종료 거래일을 대조하고 분할·기준가 변경·결측을 보류한다. 원문·해시·수집시각을 저장한 뒤에만 전송한다.
- 기존 섹터 목록 링크는 `WEEKLY_MATCH_ENABLED=false` 기본값으로 숨겼다. 신규 페이지는 noindex, sitemap 미포함이다.

## 활성화에 남은 일

연결된 Supabase의 프로젝트 목록이 비어 있어 운영 migration·advisors·실제 로그인 선택 저장을 확인하지 못했다. 기존 프로젝트 접근을 연결한 뒤 0018 적용, 해당 주 특별 일정 재확인, 첫 접수·실제 저장·종료 정산 운영 일정을 검증해야 한다. 그다음 진입 링크·검색 색인을 활성화한다. 실제 종료일 이전에 첫 주 운영 승패 정산을 완료했다고 보고하지 않는다.

주간 대진 자동 생성·예약 운영, 시즌 순위·공개 닉네임·공유 카드는 포함하지 않았다. 첫 버전의 정산은 수동 운영이므로 담당·실행 일정 확보가 접수 개방 조건이다. [운영·재시도·중지 절차](weekly-match-operations.md)를 따른다.
