## 검증 결과

- **유닛:** 최종 전체 유닛 43파일·498테스트 통과. 신규 참여·FAQ 동작 4개는 실패 재현 후 통과 확인.
- **타입:** `pnpm exec tsc --noEmit --incremental false` 통과.
- **빌드:** `pnpm exec next build` 통과. 시장 DB 다운로드·덮어쓰기를 피하기 위해 `pnpm build`의 선행 수집 단계는 실행하지 않았다. 원격 Vercel 빌드는 기존 `pnpm build`를 사용한다.
- **브라우저:** 설치된 Chrome으로 데스크톱·모바일 14개 검사 통과. 가이드 3편, 관심 목록 인증 복귀, 두 FAQ 화면, 방법론 H1 회귀를 확인했다. 기존 환영 모달은 실제 “건너뛰기” 버튼으로 닫은 뒤 검사했다.
- **시각:** 1440px·390px에서 관심 목록 안내와 FAQ 스크린샷 4개 생성, 모바일 이미지 검토. 해당 화면의 가로 넘침 및 수집한 미처리 페이지 오류 없음.
- **독립 리뷰:** 전역 H1 변경으로 기존 화면의 제목이 없어지는 회귀를 발견해 수정했다. 브라우저에서 H1 0개 실패를 먼저 재현했고, 수정 후 방법론의 H1 유지와 가이드의 단일 H1을 확인했다. 재리뷰의 추가 중요 결함 없음.
- **공개 배포 전 기준선:** 운영 홈·섹터 목록·CPU 섹터·삼성전자·랭킹·가이드의 정상 응답과 canonical/본문 확인. 비로그인 관심 목록은 복귀 주소를 보존하는 로그인으로 이동하고 개인 API는 401, 잘못된 종목·섹터는 404.

독립 QA도 별도로 브라우저 14개·대상 유닛 4개·변경 대상 lint·타입 검사와 대표 초기 HTML 6종을 확인해 로컬 커밋·push를 승인했다. 별도 탐색용 스모크의 모바일 networkidle 대기는 시간 초과가 있어, 고정 대기 대신 실제 화면 요소를 기다리는 위 브라우저 수락 검사를 기준으로 삼았다. 로컬 서버는 운영 민감 환경값을 복사하지 않은 격리된 비로그인 설정을 사용했으므로, 실제 OAuth 로그인·운영 사용자 저장·정책 오버라이드·분석 공급자의 이벤트 수신을 검증한 결과가 아니다. 운영 배포 상태는 해당 main 커밋의 READY와 공개 URL을 별도로 확인한다.

## 기존 검사 부채와 한계

- 전체 `pnpm lint`는 **기존 50오류·7경고**로 실패한다. 19개 진단 파일은 기준 커밋과 바이트 단위로 같고, 수정한 상단바의 두 진단도 기준 커밋과 같은 규칙·메시지임을 확인했다. 나머지 변경 파일의 대상 lint는 통과했으며, 이번 수정에 새로운 lint 진단은 확인되지 않았다. 규칙 비활성화나 무관한 대규모 수정은 하지 않았다.
- 로컬 하네스 전체 정적 검사는 기존 hyphen 역할명 10개가 snake_case 규칙에 맞지 않아 실패한다. 이번 작업과 무관한 사용자 하네스 정의는 보존했다. 실행별 완료 검사와 제품 검사는 별도다.
- 홈은 초기 HTML의 H1은 하나지만 최종 클라이언트 화면에는 브랜드·본문 H1이 중복되는 기존 상태가 있다. 독립 QA가 기준 소스와 대조해 기존 부채로 분류했으며, 이번에 명시적으로 변경한 6개 호출자와 구분한다.
- Search Console·Naver·Bing의 실제 색인·노출·클릭 데이터, AI 답변 인용 성과는 확인하지 않았다. 구조·본문 개선을 노출 성과 달성으로 표현하지 않는다.
- 실제 로그인 계정을 사용한 저장·삭제는 수행하지 않았다. 기존 인증 가드와 로그인 목적지 유지, 비로그인 차단을 확인했다.

## 주간 매치와 다음 순서

[최소 설계·로컬 데이터 확인](weekly-match-design.md)에 국내 1개 대진의 접수·잠금·정산 계약과 가격 조회 결과를 기록했다. 거래일 달력·가격 조정·당시 구성 종목·결측 처리 검증이 남아 있어 경기·시즌 랭킹·성과 카드는 운영하지 않는다. 이 조건을 해결한 뒤 E01, E04/E07 순서로 이어간다.

첫 반복 개선은 공개 링크·갱신일·오류 상태의 일일 확인과 검색 의도별 유입·관심 목록 전환의 주간 검토다. 스케줄러·이메일·SNS 자동 게시를 활성화하지 않았다.

## 배포와 복구 기준

승인된 대상은 GitHub `byunginhb/sector-king`의 `main`, Vercel `byungins-projects/sector-king`, 공개 도메인 `https://sector-king.com`이다. 작업 파일만 일반 커밋·push하고, 해당 커밋 SHA의 production `READY` 및 공개 URL 흐름을 확인해야 배포 완료로 판정한다. 로컬 빌드만으로 운영 반영을 선언하지 않는다.

문제 발생 시 이번 릴리즈 커밋을 `git revert`하여 정상 push하거나, Vercel에서 검증된 직전 READY 배포로 복구한다. 기준 정상 배포는 커밋 `106df6411b7e633c95a10027e30d73fd470a0484`의 `dpl_9A8GQRKGPaEH9pkqxZJMc2v8ekbw`다. 공유 main의 reset·force push는 사용하지 않는다.
